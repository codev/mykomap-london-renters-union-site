London Renter's Union - Property Licensing Map

A London Renters Union project

This map displays property licensing data for London Boroughs, as of November 2025 from various public licensing registers.

Licensing data on public registers is often out of date. Unlicensed properties are a major problem, please bear this in mind if using these maps for outreach.

This site is powered by Mykomaps which was created by the Digital Commons Co-operative.
